# OTT Streaming Content Trend Analysis — Netflix

## Project Objective
The objective of this project is to analyze the Netflix content catalogue and identify trends in content types, genres, ratings, release years, country-wise distribution, and movie durations.

## Dataset
- Dataset: Netflix Movies and TV Shows
- File Name: `netflix_titles.csv`
- Total Records: 8,807
- Total Columns: 12
- Source: Kaggle – Netflix Movies and TV Shows dataset

## Tools and Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- SQL (SQLite)

## Project Tasks
- Data loading and inspection
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Content type analysis (Movies and TV Shows)
- Genre and country-wise analysis
- Content ratings analysis
- Release year and duration analysis
- Data visualization

## Key Deliverables
1. EDA Jupyter Notebook with seven visualizations.
2. Content Strategy Memo with three actionable insights.
3. SQL queries used for core data aggregations.

## Project Structure
- `OTT_Streaming_Content_Trend_Analysis.ipynb`
- `Netflix_Content_Strategy_Memo.docx`
- `OTT_Streaming_Analysis_Queries.sql`
- `README.md`
- `netflix_titles.csv`

## How to Run the Project
1. Download the dataset.
2. Place the CSV file in the same folder as the Jupyter Notebook.
3. Install the required Python libraries.
4. Open the notebook using Jupyter Notebook.
5. Run all cells to perform the analysis.
6. Execute the SQL queries using SQLite.

## Conclusion
This project provides insights into Netflix's content catalogue through exploratory data analysis and SQL queries. It helps understand content distribution, genre representation, ratings, and release trends.
